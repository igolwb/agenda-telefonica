# Agenda Telefônica

Uma aplicação simples de agenda telefônica desenvolvida em React, que permite adicionar, editar e excluir contatos. Os dados são armazenados no Local Storage do navegador.

## Funcionalidades

- Adicionar novos contatos com os campos:
  - Nome
  - Número de telefone
  - Email
  - Apelido
- Editar contatos existentes.
- Excluir contatos.
- Visualizar a lista de contatos.
- Dados persistidos no Local Storage.

## Tecnologias Utilizadas

- React
- Bootstrap
- SCSS

## Pré-requisitos

Certifique-se de ter o seguinte instalado em sua máquina:

- [Node.js](https://nodejs.org/) (versão 14 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

Como Usar

1. Clique no botão "Adicionar Novo Contato" para abrir o formulário.

2. Preencha os campos obrigatórios (Nome, Número de Telefone, Email e Apelido) e clique em "Adicionar Contato".

3. Para editar um contato, clique no botão "Editar" ao lado do contato desejado.

4. Para excluir um contato, clique no botão "Excluir" ao lado do contato desejado.

Os dados são salvos automaticamente no Local Storage.

Estilos:

Os estilos foram criados utilizando SCSS e Bootstrap para garantir uma interface moderna e responsiva.
